# Design notes

## 2026-11-05

- gm-continue setup: `tools/gm-continue-setup.mjs` was missing from the checkout, so `node tools/gm-continue-setup.mjs` failed with `Cannot find module`. Restored it as a read-only script: it reads `work/rows/*.yml`, prints each open row as a plan line and each parked row with its `parkReason`, reports rows whose status is neither open, parked nor resolved as defects, and writes nothing. DESIGN.md did not exist in this checkout, so this file was created to hold the note.
- gm worker crash: a 19-agent scout using parallel gm.search calls made the gm worker exit with code 139. SearchVerbs::call mutated the shared searchers_ map without a lock while load_tracked replaced files_ and invalidated const pointers cached in build_index. The other gm session fixed it on origin/main in 5d9e8358ae631661546035e97c52a6ffb2f50247: serialize SearchVerbs::call under a mutex, update files_ in place with insert_or_assign and erase only vanished paths, and mask dotenv values. Regression witness: ctest "100% tests passed, 0 tests failed out of 22"; ASan "search tests passed" with no report; dotenv parity; 6 and 16 parallel run_code bodies both all ok with null exit. Before the fix, 16 concurrent bodies reproduced SIGSEGV. gm.search is safe once the new build is installed.
- Debug ledger: `.gm/witness-log.md` is untracked and its last entry is 2026-11-02; a workflow scout found its later entries stale relative to current rows and commits. Committed DESIGN.md, AGENTS.md and git bodies are authoritative, so the ledger is not a source for closure or debugging state.
- gm child-event fan-out: a 9-agent Workflow produced 654 events in one next_context. The other gm session added opt-in next_context({compactChildren:true}) in 8e8d0db: consecutive child run_code/code-call/generation events collapse into one child-range item with seqs, count, per-kind counts and query.after, while pending events and parent actions stay full. Witness on a 504-event feed: PLAIN records=94 chars=19862 vs COMPACT records=5 chars=874 summaries=1 summarized=497 seqs=[[4,500]], SMALLER true, PENDING_SURVIVED true; ctest 22/22, Node tests 17 pass.
- gm build identity: /config/.gmnew/current/gm-core --version printed only "dev", so an agent could not tell whether the search fix was installed. The other gm session landed a925479 on origin/main to report the compiled-in commit SHA from --version and a read-only build-info path, with no runtime git call. The local binary still prints dev until the manual reinstall; the commit is the witness until the version output changes.
