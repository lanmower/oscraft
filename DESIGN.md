# Design notes

## 2026-11-05

- gm-continue setup: `tools/gm-continue-setup.mjs` was missing from the checkout, so `node tools/gm-continue-setup.mjs` failed with `Cannot find module`. Restored it as a read-only script: it reads `work/rows/*.yml`, prints each open row as a plan line, reports rows whose status is neither open nor resolved as defects, and writes nothing. DESIGN.md did not exist in this checkout, so this file was created to hold the note.
- gm worker crash: a 19-agent scout using parallel gm.search calls made the gm worker exit with code 139. SearchVerbs::call mutated the shared searchers_ map without a lock while load_tracked replaced files_ and invalidated const pointers cached in build_index. The other gm session fixed it on origin/main in 5d9e8358ae631661546035e97c52a6ffb2f50247: serialize SearchVerbs::call under a mutex, update files_ in place with insert_or_assign and erase only vanished paths, and mask dotenv values. Regression witness: ctest "100% tests passed, 0 tests failed out of 22"; ASan "search tests passed" with no report; dotenv parity; 6 and 16 parallel run_code bodies both all ok with null exit. Before the fix, 16 concurrent bodies reproduced SIGSEGV. gm.search is safe once the new build is installed.
