# Agent instructions for oscraft

Comments are not kept in source: durable facts live here and names carry intent. Rule provenance that annotated Lua before the comment sweep is in git history (`git log --diff-filter=M -S'F_V 14297' -- scenarios/moba/kill_gold.lua`).

## Invariants

- **6.88g takes precedence over every other source.** A 6.88g value is used as is. When silent: analyze (our data, map files and script), then web (Dota Allstars 6.88 changelogs and wiki, map dumps, wc3 modding docs, openwar3), then a guess. Every value carries one final label in the file that holds it: `6.88g`, `web` or `GUESS`, with its source (war3map.j line, URL, or the guess's reasoning). A hero absent from 6.88g takes its Dota 2 entry as `GUESS(web)`. UNVERIFIED is not a final label; an unverified value is a `kind=unverified` provenance row.
- **ENGINE_DEFAULT is the Custom ruleset** (6.88g w3i game_data_setting=0): a value 6.88g leaves to the engine takes the Custom value, not Melee.
- Generator output is never hand-edited: edit the generator.
- Provenance sidecars: comment-free `.osd` sources keep facts in `scenarios/moba/provenance/<source-file-name>.tsv`, columns `anchor<TAB>kind<TAB>note` (kind = provenance|unverified|missing|rationale|source); read with `tools/provenance.mjs`.

## Build, CI, Pages, dev loop

- Game = GitHub Pages site; host runs in the browser over wireweave (WebRTC + Nostr), no Node game or host. Buildless page: committed ES modules and wasm, no bundler.
- `rust/rust-toolchain.toml` pins the compiler for ci.yml, pages.yml, release.yml and local builds (its hash is in wasm and maps cache keys); bump it there only.
- `ci.yml` (push to main, workflow_dispatch): job `static` runs `check-modulepreload.mjs`, `scenarios/moba/tools/check-fx.mjs`, `check-acronyms.mjs`, `check-modules.mjs`, `check-manifest-data.mjs` (scenario manifest `data` entries must be `.osd`/`.tsv` files inside the scenario dir), `check-pathing.mjs`, `gen-shops-688g.mjs --check`, `check-ability-balance.mjs` (vs a committed 6.88g reference); job `browser-smoke` builds the page and checks lobby, console errors, hero icons (`scripts/perf/page-smoke.mjs`).
- `tests.yml` is workflow_dispatch only: workspace tests (nextest 0.9.149), oscraft-gate, wasm32 + wasip3 compile, native/wasm state-hash parity, mapexport determinism, wire round-trip.
- `pages.yml` builds wasm and maps from source, lays the site out with `scripts/layout-site.sh` (shared with `scripts/dev/stage.sh`; drops vendored trees, docs, scenario `tools/`), deploys behind wire and static gates, compares the live page with the build. pages.yml is hashed into the wasm cache key. Page wasm: opt-level s + lto + strip. Parity: `mod-host` `parity_hash` on moba for 600 ticks must equal `scripts/parity/wasm-hash.mjs`.
- `scripts/perf/first-draw.mjs` transfer accounting counts every served request, and `checkWasmWatch()` HEADs the wasm every 2 s, so the perf server answers HEAD headers-only (etag/last-modified added for the signature; body counted at 0); a normal boot fetches web_bg.wasm exactly once per load (481898 B gzip in the 5f4c3cd build), and loads differ by HEAD cadence only.
- `first-draw.yml` runs after a successful pages run (`workflow_run`; downloads that run's `site-expected` artifact, or the newest successful pages run on dispatch) with `cancel-in-progress: true`, so the 10 s first-draw gate never holds the pages concurrency queue or reddens a deploy. Live freshness proof is the deploy job's `compare.mjs --expect-sha` (cache-busted); GitHub Pages serves every file `cache-control: max-age=600`, so a browser can show an earlier build for up to 10 minutes after a deploy.
- First draw (`scripts/perf/first-draw.mjs <site> --loads=3 --ceiling-ms=10000`): the ceiling is the owner's call, never change it; CI medians measured 8.7-9.8 s after the model-fit deferral (11.3-12.7 s before; runs 40536986555=9842, 40536986555's successor 40538066466=8720) against local medians of 2.9-6.7 s on the same CI-built artifact (load 1 skews high in both). The gap is environment-led: CI boots the game faster (game phase 162-279 ms vs local 613-1160) but pays 2-3x in the preview/first-raster phase (8.5-9.2 s vs 3.1-6.1 s), so treat CI and local numbers as separate scales. Serial fetch beats parallel.
- Dev loop: `scripts/dev/stage.sh` (`SKIP_PACKS=1` for speed), then `node scripts/dev/serve.mjs [--port=N]`; js/client, scenarios, mods served live, pkg and version.json from the stage. Localhost loads `hmr.js` (~80 fetches per module): local request counts are not page footprint. Disable the CDP network cache before load.
- Scripts take root from `import.meta.url` or own dir, never a machine path; Python runs as `python3 -I`. Archives are built inside the stage with colon-free names (GNU tar on Windows treats `D:` as a host).

## Lua mod host and sim

- `rust/crates/mod-host`: piccolo 0.3.3 vendored at `rust/vendor/piccolo` (fixes in its README: RawTable grow, assignment order, missing call args read nil; gate `lua-missing-args-nil`). A pack = modules, one Lua file each named by stem; a module returns a hooks table or (old style) nothing and its globals are hooks. `require("<name>")` takes a string literal (dependency order; cycles reported; loaded once). The `piccolo` feature is the mod VM: the native host and the wasip3 guest both run mods on it.
- Sandbox: no string/table/file library (ordered walks use `ascending_keys`); no max HP in the API; `a, b = b, a` writes the first target before evaluating the second; death hooks have a small step budget; `game.cmd_cast` only queues (controls.lua refuses range first); the sim resets a reused slot's armour scale, speed bounds, miss chance on spawn (unit_rules.lua re-sends); `game.ticks()` is the clock.
- Draft modes cm cd rd sd rv (GAMEPLAY_PARITY DRF): `draft.lua` (machine, `draft`/`draft_pool` panels) and `draft_data.lua` (the 112 `P3` heroes in war3map.j index order, 1..59 Sentinel half, 23 techies, attribute digits). Lobby Start begins the draft (seats ready, heroes empty, `modes.picks_free`), Start again once every seat holds a hero; `modes.restrict` narrows `modes.allows`; panels.lua only routes `pick`, `start`, `draft_clock` and `draft.blocks` the other calls. The lobby sim does not tick: the draft clock is `game.timer("draft", 1, ...)`, so a real lobby needs the page to tick the sim or send ui `draft_clock {ticks}` (host key, at most 64). No `string.match` in the VM.
- A raising hook is off for that module only. A module failing load keeps last-known-good hooks, else skipped; failed build restores sim, regions, queued commands. Containment: FUEL_PER_STEP up to MAX_STEPS (`instruction_limit`); Lua memory cap counts all modules. Wasm guests are `panic = abort`: natives run under guard_native. `--features fault-injection` reads `-- wasip3-fault: panic at <tick>` from mod source.
- Step order: sim tick, zone/unit events, systems, queued commands, due timers, on_tick; commands from on_tick/timers wait a step. `on_died(unit, killer, killer_player, bounty, victim_player, killer_attributed)`: its commands apply before systems'; `feed_death` returns them unapplied.
- Hook defaults: no on_skill_up/on_cast_request allows; a Lua error or malformed on_request answer refuses. `on_state_replaced` runs after sim swap/load. `sim()` is a shared borrow that may nest; `sim_mut()` lasts one statement. `allow_cast` refuses FLAG_PASSIVE. A teleport lands only when its channel ran out.
- Natives take raw Q16.16 for positions/radii unless a `fixed` whole-unit scale is named; NaN/inf refused. `game.effect`/`ui_event` are not hashed or replayed. Neutral player 255 is an enemy of all. `game.tree_add` refuses rectangles past 32 cells a side.
- Tools: `mod_check <scenario-dir> <mod.lua> [ticks]` (`--fog off`); `parity_hash <pack-dir> <ticks> <out-dir>` prints `state_hash=<16 hex> ticks=<n>`; `payout_parity` per backend (default vs `--no-default-features --features "piccolo build"`); `build` feature gates osdt generate (guests do not link starlark).
- `scenarios/moba/init.lua` lists features in hook order: `first` features hold a death so later death hooks read it unrewarded; `last` sets next tick's armour, speed bounds, miss chances. `aegis` loads first. `declare_defeat` is a no-op; the mod calls `declare_victory`. Creep acquire ranges are 6.88g UnitWeapons game units at 125/8 milli (Ghoul 500, Necromancer 600, Meat Wagon 800).
- Units/determinism: 15.625 milli per map unit (`config.milli(round(units*15.625))`); 125/8 milli per game unit; 16 ticks/s; sim HP Q16.16 (percent of current life = `unit_hp*percent/(100*65536)`); `hp_per_tick` thousandths. ## Items and economy

- Inventory: ten slots per unit (six main, three backpack, one neutral; stash has no neutral slot). Only main and neutral are active. Bonuses never stored: `change_items` applies the `item_totals` difference; `best_only` stats take the largest value, the rest add. Acquire takes held copies inventory first, then stash.
- Refresh effect `p0` bits: 1 resets ability cooldowns, 2 item cooldowns (the used item keeps its own). `gen-items.mjs` (`apply-items-688g.mjs` layers `items_688g.tsv`), `gen-shops-688g.mjs`; a recipe component must be declared before its item and cost no more.
- `tuning.osd` = TUNE: every key present and in range or the map is refused (`structure_scan_cells`, `teleport_ring_*`, `best_only`, `xp_curve` for levels 2-25: moba from 6.88g misc.ini NeedHeroXP, duel-routes curve UNVERIFIED, recalled). Engine holds one rank per ability slot, per-player research bits, xp (no levels), item requests answered by mod `ItemVerdict`.
- Attributed units: `attr_rules.txt` `key=value`; every engine key present or refused. `unit` lines from `scripts/gen-units.mjs` (hundredths for attributes, gains, armor, mana regen; `bat` hundredths of a second). A dead attributed unit stays dead until the mod calls `set_respawn`.
- Damage path: armour, damage response, shield, life; ability damage skips armour and applies the magic keep percent. Shields absorb before life. Roles come from unit filters, never names.
- Creep bounty: `unit_extra(..., reward_min=, reward_max=)` holds the UUR range (war3map.j 91684-92300); `Sim::roll_bounty` rolls one integer per death on the sim RNG. The healing ward pays 0; every allied kill halves table xp (W_R 93567), so `deny_xp_pct` is 50.
- Goblin's Greed (A0O3, `kill_gold.lua`): each enemy non-structure death by the hero (or summon) pushes a tick on a ring of eight unit counters, 30 s each (HUX). Gold = min(stack*3 + rank*2 + 4, 4 + 8*rank), stack counted before the kill (W_R/HWX order UNVERIFIED); creeps pay inside the bounty (W_R 93587-93597), heroes at once (HWX 44729-44733).
- Deny below 25% (P5E-P7E 30561-30573): the ten P6E buffs are Doom (B32S), Viper Strike (B001), Shadow Word (B0AP), QoP Shadow Strike (BEsh), Venomous Gale poison (B0AQ), Curse of the Silent (B05D, B05M, B05N, B05O). `deny_mark.lua` marks unit-target casts; area/delayed ones carry a `timed_stat` of `S_DENY_MARK` (stat 30). Otherwise: structures below 10% except ancients, other non-hero units below 50 (`deny_pct`).
- Hero acquire range: `unit_extra(<hero>, acquire=)` from unit.ini (`work/combat/timing.tsv`, hy3d project); non-6.88g heroes carry none. `lanes.lua` `hero_step`: an idle hero with a hostile non-structure target in range attack-moves to it; a changed order ends it.
- Sale refund (`store.lua` `sale_refund`): floor(cost/2), no window; charged items refused before payout (war3map.j 24914-24920).
- Bloodstone: a living holder gains one mana per charge each second (`respawn_terms.lua` `terms.trickle`, Q7V 18991-18996, timer Q8V). Kelen's Dagger locks 3 s after a hit above `heavy_hit_min` (attr_rules.txt 2; S_V 19465, S1V 19489): sim `heavy_hit` stamp, `game.heavy_hit_age`.

Kelen's Dagger locks for 3 s after a hit above `heavy_hit_min` (attr_rules.txt 2, 6.88g S_V 19465, S1V 19489): sim `heavy_hit` stamp, `game.heavy_hit_age`. State version 58 added `shield_lock` and `heavy_hit`.
- Item value sources: a value 6.88g lacks is labelled `web` (dotaconstants items.json, Dota 2 modern) or `GUESS` with its reason in items_688g.tsv stat_note: aura radius 1200 units is web, Pipe mana 100 is a GUESS (DotA-era figure recalled, dotaconstants 150 is modern Dota 2), ranged reach 3125 milli is 6.88g unit.ini, Stout Shield 55 is the 6.88g ability data over the Ubertip 50.

## Sim core (rust/crates/sim)

- Attack feel (`swing.rs`): an attack holds the unit for the attack point (`attack_point_ms`, scaled by attack speed); a changed strike target, stun, disarm or out-of-reach target during that wait cancels the swing (cooldown stays spent). The hit starts the backswing (`backswing_ms`, no movement). Ranged launches a missile (`missile_speed`) that tracks when `missile_homing`, else hits only if the target is still within radius plus half a cell; `missile_arc` is presentation only. Fields from `weapon_feel_688g.tsv` via `tools/apply-weapon-feel.mjs` (unstored = 0, except lane creeps).
- `persist.rs`: `STATE_VERSION` is the only accepted save version (else `BadVersion`); bump with every layout change and say what changed in the commit body. Little-endian, fixed order. Not saved: catalog (caller loads same map first), bucket planes, scratch. State hash FNV-1a in fixed order; mod digest computed once per load.
- Transient (not hashed or saved): `casting_slot`, destination request log, fired-behaviour queue, fx queue and hit log, cast logs, kill events, last killer, item generation counter. Hashed only once set: aggro class/hold/strike target, ground items, facing. Named unit counters (`game.set_counter`, zero values omitted), per-slot item drop locks and per-unit borrowed spell blocks are hashed and saved (state 59); the spell-block log is transient.
- `tick.rs` order: buckets, fog cadence, flow fields, buffs, projectiles, then per unit upkeep, routing, steering, integration, attack. `Instant::now` traps on wasm32-unknown-unknown.
- Movement: stop and hold are the same (sim never chases). A ground unit within one tick of a stop lands on it only if both corner cells of the jump are walkable. `strike_measure` measures to a unit centre or the nearest blocked cell inside a structure's radius plus one cell; `strike_stop` is 3/4 weapon range. A snap onto a friendly footprint is refused.
- Unit clearance (`movement.rs integrate`): a ground unit's collision circle (`radius`, 6.88g unit.ini) keeps `radius` from every blocked cell edge; a step coming closer is refused unless it does not close the gap. Cells are 64 units, blocked when any 2x2 6.88g pathing cell is. Units block each other by radii through `separation`.
- Pathfinding: cell bits BLOCKED=1, cliff=2, ramp=4, TREE=8; SOLID = BLOCKED|TREE. Callers that change blocking call `Pool::invalidate`. Diagonals need both orthogonal neighbours walkable. Elevation unused by movement, vision, combat. A* ties break on smaller cell index. `is_summoned` (lifetime unit or illusion) feeds the half-xp rule.
- Loader: OSDT little-endian, every index bounds-checked, version per `rust/crates/data/FORMAT.md` (any other rejected). Name lists (SNAM, EKND, FNAM, MCND, DKND) non-empty and unique; SNAM exactly STAT_COUNT names. `0_names.osd` (both packs) sorts first and fixes list positions: renaming/reordering changes the image and the sim refuses a map whose lists differ from its loader's.

## Client JS

- Sim never reads display data (terrain heights, weight maps). Cliffs (tiles.js): a drop of one 6.88 cliff level (128 z) or more is a wall; a drop beside water is never a ramp. Load gate (load_gate.js) never opens on a timeout; ice.js STUN only. Older wasm lacks some exports (page degrades, never guesses); Building = bit 2048 of filter mask. props.json alone names prop models.
- play.js: failed assets are recorded (`recordAssetError`), no fallback drawing; flags `?nomods=1`, `?shadows=0`, `?ambient=0`, `?relay=`, `?host=1`, `?hmr`; `window.__fxOff` is the CI probe for effect frame cost.
- `recoverGame`: a wasm trap leaves the Game unusable; rebuild from the last snapshot with mods off; over `MAX_RESTARTS_IN_A_ROW` stops the sim; unrestorable snapshot reloads `?nomods=1`. All tick-path Game calls stay inside the try or the rAF chain dies.
- `js/client/play.js` live stage marks land on `window.__stageMarks` (build3d timing trail); the splat KTX2 texture path relies on `decoders.loadBasis()` warmed at module init. First frame draws the terrain, water and splat; unit meshes stream in through the deferred pump (`queueUnitModelBacklog`, UNIT_MODEL_CONCURRENCY 4) and `collectUnitDraws` re-queues any type it meets unbuilt.
- Swaps (swap_protocol.js): only the host announces and sends PACK_FILE; commit at T when every peer is ready, else re-announce up to `SWAP_MAX_DEFERS`, then cancel; a peer without the image keeps its old Game.
- Hot reload (hmr.js, `/__hmr` SSE): a module exports `hmrReload(mod)` running on the NEW instance (inputs on `globalThis.__oscraftHot`); no hook reloads the page; the wasm path concatenates ".wasm" (the Pages check reads literal ".wasm" names as root files).
- Packs (pack.js, pack_load.js, pack_sync.js): no code the page runs (.js .mjs .html .wasm .ts refused). Icons ship as one atlas per category through `build-packs.mjs`.
- CLIs: `node js/host/guest.js [--ticks=N] [--reps=N] [--peers=1,8,32]` prints RESULT: PASS|FAIL (exit 0, 1, 3 on codec error); `node js/client/editor-check.mjs [osdt-data dir]` edits map.bin, exports map.osd.
- mods/: one chunk per mod, so CI joins `bot_lib.lua` before `bot_unit_example.lua` (`bot_probe.lua` appended); bot_lib cannot require shared/xp.lua. Script-unit map cell is 64.
- `scripts/gamesparks-bootstrap.mjs` may rewrite the moba manifest's `gamesparks` block when run; manifest `data[]` stays OSDT-only (`scripts/check-manifest-data.mjs` gates it).

## Scripts, generators, assets

- Generators rewrite whole files: `gen-heroes.mjs` -> units_heroes.osd (per-hero model only via its `HY3D_MODEL` table: an unlisted hero gets an empty model and the page refuses to start a match), `gen-abilities`, `gen-items`, `gen-shops-688g`, `gen-trees-688g`, `gen-hero-acronyms`, `gen-ability-keys`, `gen-reference`, `gen-ui-fill`. `--check` (apply-pathing, gen-trees, gen-shops, gen-lane-routes, gen-neutral, buildings, apply-items; all `-688g`) exits 1 when the committed file differs. `gen-reference-map.mjs` overwrites map.osd with the older reference ruleset: run only on purpose.
- Map conversion (`convert-688g-map.mjs`, `buildings-688g.mjs`): z-offset 384 is the 6.88g calibration; water = W3E corner flag 0x40; tile id from ground tileset name (Cdrt/Cdrd lane, Cvin dirt, else grass); teams alternate by seat (even Sentinel, odd Scourge) while player 0/1 own buildings, couriers, spawners.
- `pathing-688g.mjs`: pathTex pixel = one 32-unit cell, red > 127 unwalkable, authored at facing 270 and turned counter-clockwise; doo flag bit 0x2 clear = non-solid. Tree destructables form the sim tree layer (trees_688g.lua).
- Props: `shipped_kind` `a|b|c` in prop-types-688g.tsv spreads records round-robin. `prop-sizes.mjs` is the one scale rule; a `-skinned` model is a unit unless props.json references it. `gen-prop-types-w3.mjs --types <prop-types-w3.tsv>` (hy3d map-diff pass): a code no source names is dropped.
- Asset prep: prep scripts skip by content hash in `prep-manifest-*.json`; prep-ktx never calls `reorder()` (client fits over every POSITION vertex). `pack-package.mjs` splits packs over 25 MiB into parts; its extension allow-list must match `js/client/pack_load.js`. `vendor-cdn.mjs` re-fetches from the `// Vendored from <url> by ` header: keep that text.

## Area notes: crates

- Data: FORMAT.md is the layout; a name's index is its code. Units: milli-units, ticks, `damage_factor` Q16, scale thousandths. AXTN modifier `cond`: 0 scepter, 1 shard, 2..=9 talents; `effect` from `MOD_FIELD_FIRST`: +0 cooldown, +1 energy, +2 cast range, +3 cast point.
- Replay format 3: `chk` at tick t precedes the `segment` at t, which precedes t's commands; hashes taken after orders, before the step. v1/v2 still parse; retired fields written 0. Refused commands are recorded (they feed the hash).
- wasip3 (own workspace, excluded from `rust/Cargo.toml`): `COMMANDS` and `wit/sim-component.wit` synced by hand; fixed-seed getrandom. Tests: `cd rust/crates/wasip3 && cargo test --features fault-injection --no-fail-fast`.
- Gate: `GATE_PACK` picks the pack; pack commands apply two ticks late. Crowding checks place no tower (its 2.25-tile body moved units out of reach). `profile.test` optimises sim, piccolo, mod-host, osdt-data (`moba_ticks` takes 47 s unoptimised).
