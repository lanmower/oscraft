# 1. Scope
The baseline is a classic MOBA rule set. Every system is either part of this baseline or listed as a Brainrot original.

| Core rules | Brainrot originals |
| --- | --- |
| Level cap 25 | Clout (signature resource) |
| Ultimates unlock at 6, 11, 16 | Go Viral |
| Four abilities, three attributes | Stan (creep buff) |
| Lanes, towers, content mills, Original Post | Ratio (death transfer) |
| Boss objective with a revive reward | Repost chain |
| Delivery Drone, shops, wards, day/night | Rebrand |
| Ultimate upgrade item | Go Private (padlock) |
| Attribute stat rules | The Trend and Screenshot |
| Gold, XP, bounties | Parasocial tether |

Remix policy: a Brainrot original may only sit in the slot of a classic system (see section 2). It may add a decision. It may not add a new resource that nobody can read. Numbers marked verify are set in the balance pass.
