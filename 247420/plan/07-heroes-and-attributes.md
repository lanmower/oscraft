# 7. Heroes and attributes
Every hero has three attributes, a primary attribute, and a base stat block. Heroes level to 25.

### Attributes

| Attribute | Per point | Notes |
| --- | --- | --- |
| Strength | +20 max HP, +0.1 HP regen | Melee durability |
| Agility | +1 attack speed, +1/7 armor | Armor per point is 1/7 |
| Intelligence | +12 max mana, +0.05 mana regen, +1% spell amp per 16 INT | Spell amp is additive with item amp |

Primary attribute: +1 damage per point of the primary attribute. There is no Universal attribute.

### Base stats

| Stat | Value |
| --- | --- |
| Base HP | 200 |
| Base mana | 50 |
| Base movement speed | 300 |
| Maximum movement speed | 522 |
| Melee attack range | 150 |
| Ranged attack range | 500 default, 300 to 700 |
| Base attack time (BAT) | 1.7 melee, 1.5 ranged |
| Turn rate | 0.6 s |
| Magic resistance | 25% base |

Each hero can override the base attack time and turn rate. These two values define the hero's feel.

### Level

- Level cap: 25. Level comes from XP (section 5).
- Ability points: one per level, plus the ultimate unlock rule.
- Ultimates unlock at levels 6, 11 and 16. They max at level 3.
- Standard abilities max at level 4.
- Level 25 is the final level. There is no stat skill for leftover points.

### Respawn

Heroes respawn at their Spawn Lounge. Respawn time is 5 + 3.8 × level seconds (section 5). Heroes spawn with full health and mana.

### Hero shape

Every hero is one of three silhouettes: circle (support), square (durable), triangle (aggressive or mobile). Hero archetype, silhouette and shape language are in section 17.
