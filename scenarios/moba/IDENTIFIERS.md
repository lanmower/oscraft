# Default Dota/MOBA identifiers: acronyms only

Active default Dota/MOBA hero identifiers are acronyms. Full Dota names and source slugs are historical/source provenance only, never active keys in the default experience.

Chosen strategy: non-destructive generated overlay. `scenarios/moba` is the historical source pack and is not rewritten. `scenarios/moba/tools/gen-moba-acronym-pack.mjs --apply` generates `scenarios/moba-acronyms`; `js/client/pack_load.js:6` sets `PACK_PARAM` to `scenarios/moba-acronyms` when no `pack` or `package` query parameter is present. Therefore `/js/client/play.html` and `/` present acronym-only IDs. `?package=scenarios/moba` remains the historical source pack; `?package=scenarios/bota` remains the opt-in BOTA pack.

The authoritative display acronym table is `scenarios/moba/hero_acronyms.lua`, generated by `scenarios/moba/tools/gen-hero-acronyms.mjs`; the derived pack's `identifier-map.tsv` documents the complete deterministic fullname-to-acronym mapping. See `scenarios/moba-acronyms/IDENTIFIERS.md` for the generated table.
